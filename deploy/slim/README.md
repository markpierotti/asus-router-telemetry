# Slim deployment moved

[home-lab](https://github.com/markpierotti/home-lab). That repository consumes a pinned
collector revision from this repository. See its
[deployment examples](https://github.com/markpierotti/home-lab/tree/main/deploy/slim).

The collector service contract remains illustrated in
[collector/examples/rtax-collector.service](../../collector/examples/rtax-collector.service).
Earlier deployment source and reviews remain in this repository’s Git history.
